# PDF Page to AI

Turn PDF pages into **AI-ready packages** with text, image & structured metadata.

Every page becomes a self-contained folder:

* `page.png` – rendered page image  
* `page.txt` – clean plain text (digital or OCR)  
* `page.meta.json` – structured metadata that AIs and RAG systems love  

Metadata includes document title, author, page number, dimensions, word count, extraction method, and a short preview — ideal for **ChatGPT, Claude, local LLMs, and document-AI pipelines**.

## Why this exists

Raw PDFs are awkward for language models. A clean text file + image + machine-readable JSON per page lets you:

* feed pages individually to an LLM
* build RAG indexes with rich filters
* keep provenance (source file, page N of M, extraction method)

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

**OCR (optional but recommended for scanned PDFs)**

```bash
# Debian/Ubuntu
sudo apt install tesseract-ocr

# macOS
brew install tesseract
```

## Usage

```bash
python pdf_page_to_ai.py --input-dir ./pdfs --output-dir ./pages_for_ai
python pdf_page_to_ai.py -i some.pdf --force-ocr --dpi 300
```

### Output layout

```
pages_for_ai/
  MyDoc/
    page_001/
      page.png
      page.txt
      page.meta.json
    page_002/
      …
```

### Example `page.meta.json`

```json
{
  "source_file": "MyDoc.pdf",
  "document_title": "My Document Title",
  "document_author": "A. Author",
  "page_number": 1,
  "total_pages": 42,
  "page_label": "1 of 42",
  "width_pt": 612.0,
  "height_pt": 792.0,
  "dpi": 200,
  "extraction_method": "digital",
  "char_count": 1840,
  "word_count": 312,
  "has_images": true,
  "preview": "First sixty words of the page…",
  "extracted_at": "2025-10-02T18:00:00+00:00"
}
```

## Options

| Flag | Default | Meaning |
|------|---------|---------|
| `-i / --input-dir` | `./pdfs` | Folder of PDFs (or a single PDF file) |
| `-o / --output-dir` | `./pages_for_ai` | Root for per-document page packages |
| `--dpi` | `200` | Render DPI for page images |
| `--force-ocr` | off | Always run Tesseract |
